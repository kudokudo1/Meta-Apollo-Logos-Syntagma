## 2 // RULE PLACEMENT

- **Syntagma OPERATE:** enduring shared rules for agent behavior, permissions, communication, reporting, semantic UI contracts. Promoting a new rule requires operator authority, provenance, scope and verification.
- **Meta Apollo Logos MODEL:** family-level governing design language and principles.
- **Owning project MODEL / code-adjacent contracts:** technical architecture and executable invariants. Its OPERATE covers how to run; EVIDENCE covers observed verification; DEV covers test machinery.
- **How I Think / Poioumenon:** personal thoughts, language experience, creative identity, stories, long-form evidence and archaeology. Do not silently normalize them into universal rules.
- **Syntagma EVIDENCE:** checks and observations concerning Syntagma rules and migration, not first-person personal evidence.

Rule ownership is distinct from *source evidence*. An observed runtime issue is not automatically a new canonical semantic rule, and a shared rule does not certify a particular QML implementation.
